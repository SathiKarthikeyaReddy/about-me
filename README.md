# Personal Portfolio & Engineering Showcase

A modern, responsive, and performance-optimized personal developer portfolio and engineering showcase designed to present full-stack applications, interactive data products, and technical accomplishments.

---

## 🌟 Features & Highlights

- **Interactive Project Showcase**: Dynamic catalog driven by structured JavaScript data (`projects-data.js`) supporting project previews, tech stack badges, and deep-dive modal views (`project-details.html`).
- **Responsive & Accessible Design**: Crafted using vanilla semantic HTML5 and modern CSS3 (Flexbox/Grid, smooth gradients, media queries) ensuring flawless experiences across mobile, tablet, and ultra-wide displays.
- **Dynamic Client Interactions**: Clean JavaScript modules for smooth scrolling, interactive project card expansion, live filtering, and interactive contact actions.
- **Asset Management**: Embedded asset and resume download support in `/Downloads`.

---

## 🛠️ Technology Stack

- **Markup**: HTML5 (Semantic elements, metadata, responsive viewport)
- **Styling**: CSS3 (Custom CSS properties, CSS Grid, Flexbox, responsive typography)
- **Scripting**: Vanilla JavaScript (ES6+ Modules, DOM API, dynamic rendering)
- **Deployment**: Static Web Hosting (compatible with GitHub Pages, Vercel, Netlify, Cloudflare Pages)

---

## 📂 Project Structure

```plaintext
about-me/
├── index.html              # Main landing page & portfolio hero section
├── project-details.html    # Detailed project modal & extended descriptions
├── projects-data.js        # Centralized JSON/JS project metadata repository
├── script.js               # Dynamic UI rendering, event listeners, and filtering
├── style.css               # Main visual styling, design system, and animations
├── project-details.css     # Dedicated styling for modal and deep-dive cards
└── Downloads/              # Static downloadable assets (e.g. Resume, CV)
```

## 🚀 Local Development

Since this is a lightweight, zero-dependency static web application, no build steps or package managers are required.

### Quick Start:

1. Clone the repository:
   ```bash
   git clone https://github.com/SathiKarthikeyaReddy/about-me.git
   cd about-me
   ```

2. Open in browser:
   - Double-click `index.html` directly in your file manager, or
   - Use a local development server such as VS Code Live Server or Python:
     ```bash
     python -m http.server 3000
     ```
   - Open your browser at `http://localhost:3000`.
